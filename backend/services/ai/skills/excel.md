# Excel export skill

This file is read fresh on every agent turn, so edits apply to the next message with no restart.
The `json` block below is the house style the code applies to every file. Change any value you like;
a value that is invalid (wrong colour, wrong type) falls back to its default and is logged, it never
breaks a file. Everything after the block is the guidance the AI reads before making a spreadsheet.

```json
{
  "headerFill": "1F4E79",
  "headerFont": "FFFFFF",
  "titleSize": 14,
  "moneyFormat": "\"RM\"#,##0.00",
  "dateFormat": "yyyy-mm-dd",
  "freezeHeader": true,
  "autoFilter": true,
  "totalsRow": true,
  "maxColumnWidth": 50,
  "footer": "Generated by AI Treasurer on {date}",
  "aiNote": "Prepared by AI - check the figures before using them."
}
```

## When to make a spreadsheet

- Only when the user asks for a file, a spreadsheet, an Excel/xlsx, a download or an export.
  Otherwise answer in the chat.
- At most one file per request unless the user asks for several.

## Which tool

- Real treasury figures (receipts of one team or of every team, the budget overview of all teams) must
  come from `generate_report`. Leave `team_name` empty to export every team's receipts in one file.
  It reads the data itself, so the numbers are exact. Never retype those numbers into
  `generate_spreadsheet`.
- Use `generate_spreadsheet` only for content you write yourself: a budget plan, a template, a
  checklist, a comparison the user described. Never invent figures and present them as real records.

## Shaping a generate_spreadsheet table

- Short title that says what the file is, e.g. "Q3 event budget plan".
- One sheet per topic, sheet names under 31 characters.
- First column is what each row is about. Keep columns few and clearly named.
- Put amounts as plain numbers (no "RM", no commas) and list those column names in `money_columns`.
- Put dates as YYYY-MM-DD and list those column names in `date_columns`.
- No formulas: the file adds a totals row for money columns itself.

## After making the file

- Tell the user the file is ready below your message, in one or two sentences. Mention what it
  contains. Do not paste the whole table into the chat again.
